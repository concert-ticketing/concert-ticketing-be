# Ticketing
> 내가 원하는 콘서트를 찾아보고, 예매할 수 있는 웹사이트
<br>

### 개발환경 🛠️
>
> Java 17.
> >
> Spring Boot.
> > 
> Next.js
> >
<br>

## 0. 팀원 🧑‍🤝‍🧑

| 팀원 | 담당 | 파트 |
|:---|:---|:---|
|김보석| Back End | 홈 API, 예매 API, 결제 API, OAUth, ERD 작성 |
|서동진| Back End | 콘서트 관리자 API, 콘서트 생성 API, 마이페이지 API, ERD 작성 |
|최연우| Front End | 홈 화면, 마이페이지, 콘서트관리자 페이지, 서버관리자 페이지, 로그인 페이지 |
|박재희| Front End | Front 초기 세팅, 콘서트 관리자 페이지, 좌석 선택 페이지 |

## 2. 개요 📑

### 2.1 상세 내용
> 0. 시작페이지
```
1. 서비스에 대한 전체적인 설명
```

> 1. 메인페이지
```
1. 콘서트 홍보 및 이벤트 배너
2. 로그인 / 로그아웃
3. 콘서트 목록
4. (로그인 시) 마이 페이지

```

> 2. 마이 페이지
```
1. 자신이 쓴 글 표시
2. 예약 내역 표시
3. 관심 표시한 글 표시
4. 문의 내역 표시
```

> 3. 콘서트 상세정보
```
1. 글 작성과 좋아요 기능
2. 댓글 작성과 익명 댓글
3. 상세 이미지 및 썸네일 표시
```

> 4. 콘서트 관리자
```
1. 콘서트장 구역 설정
2. 콘서트 정보 생성
3. 콘서트 이미지 추가
4. 콘서트 좌석 생성
5. 생성된 콘서트 수정
6. 생성된 콘서트 댓글 관리
```

> 5. 서버 관리자
```
1. 회원가입한 콘서트 관리자 허용
2. 유저 관리
3. 배너 관리
```

> 6. 결제
```
1. Kakao Pay 결제
```
